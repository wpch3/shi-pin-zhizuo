## 可以采用的叙事方式（讨论方案）

1. 两图小短篇：一个小瞬间、一组铺垫与回应或反差，台词不必机械规定每图两句。独立标记番外/实验，不自动算第八话，短不等于把完整事件硬砍成两张图。
2. 短篇或完整一话：按事件所需篇幅，包含起因、过程、情绪变化和收尾，不强制固定页数。
3. 家庭群像：同一目标中不同家人的选择和互动；双人搭档：展示不同两人之间的相处，不局限于二弟与各人的组合。
4. 各自生活：妹妹校园、二弟的工作或个人休息、姐姐的活动；依照用户确认的人物资料，不擅自固定二弟职业或增添已发生经历。
5. 新人物渐进登场：隔壁姐姐、隔壁妹妹、小姨按故事需要逐一介绍；新角色并非已经安排进正文。
6. 连续小篇章：一件事分几话，例如前期准备与出游；每话仍有独立趣味。公园野餐、游乐园、游泳馆是未来备选，具体顺序和话数未定。

篇幅依据实际故事选择：画面动作、视线、表情和对白共同叙事；无对白不是自动加字，每张也不必固定两句。现有完整章节不因实验而缩短或改动。新完整话依此前约定整理PDF完整版、轻量PDF与Markdown，图片保留原稿；短篇的交付形式尚待商定。
