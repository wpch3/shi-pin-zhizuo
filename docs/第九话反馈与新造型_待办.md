# 第九话反馈与新造型｜待办与讨论

## 用户检查意见与优先次序

- 用户检查后指出：**第九话第一页画风有些飘，脱鞋过门动作有些不自然**；除这两点外暂未发现其他问题。记作用户反馈，不推断整话气泡、排版、标题已验收。
- 用户明确要求这一轮先整理仓库和讨论服装，**先不修第九话，也不生成新服装**；此后整理优先、再按安排生成。整话完成并验收后记得放进分格式阅读区。
- 后续修正时对照已确认的第八话画风锚点、既有人设和第九话连续构图；先检查01画风漂移具体表现，再设计自然脱鞋动作、逐只核对手脚与门槛空间，不改变确认过的故事与形象。当前未重画。

## 用户要求的三张后续新图

1. **隔壁妹妹的华丽花滑短裙服**：她是10岁就能完成 **3F（后内点冰三周跳 / 三周 Flip）**的花滑天才；整套表演服加花滑鞋，年纪感、活动性与安全得体兼顾。成绩与训练经历不凭空补定；这是造型需求，不暗示第九话已出现滑冰比赛。
2. **隔壁妹妹的完整 Cos 服**：用户要求明确 Cos 什么，不能只有蝴蝶结。她的原设已有[小恶魔哥特风完整服装](../art/角色形象区/新人物_用户预案/隔壁妹妹_花滑与cos_用户原图.jpg)。建议以其为基础发展原创「小恶魔」角色：深红与藏蓝或黑色协调的上衣、层叠裙、可拆的蝴蝶结、角与小翅膀配饰及相配鞋袜，保留橙棕双马尾和小学年龄感；第九话的布结是整套配件之一。**这只是方向建议，具体角色、配色与细节待用户裁定，不算已经完成的剧情或定稿。**
3. **邻居姐姐的 VTuber 虚拟形象**：制作可与现实侧辫形象区分的完整虚拟角色，仍保持作品画风，形象和设定先供用户审核；不要以此假设姐妹以外的人知道她的隐藏身份。

## 其他服装的建议

- 四位主角各已有[两套用户认可的新造型](../art/角色形象区/四位主角_造型v1/造型逐页.md)，连同原造型足以覆盖一般居家与外出，不必为了凑数立即增加；出现演出、节日、宴会、主题出游时再按各人性格和场景设计正式或华丽服装，保留原衣发且明确换装过渡。
- 小满如需特殊场合造型，优先童趣、舒适方便活动；姐姐可偏简洁雅致，江家妹妹偏清新活泼，二哥可有合身但克制的正式外套，具体造型均是建议不是已确认设定。
- 小姨已有[用户原设](../art/角色形象区/新人物_用户预案/小姨_用户原图.jpg)及[一套日常立绘候选](../art/角色形象区/新人物设定试案v1/小姨.png)，后者尚未单独确认。暂时足以讨论形象，不必立即新增；等确定她登场场景再考虑补一套便于家中活动的居家造型，或对应聚会的时髦外出装，不推定她的年龄、职业或额外经历。
