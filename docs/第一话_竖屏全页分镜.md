# 第一话《我姐休假回来，直接把我预约了》

## 当前制作规格

- 作品名：《星辰落进灯火里》。
- 每镜一张完整竖屏漫画，1440×2560，9:16。
- 不做左右分栏，不做四格拼页，不制作口播、旁白或视频。
- 用户自行配乐、控制停留时间并制作视频；不再以15秒为时长限制。
- 本话包含1页双人封面和7页正片，姐姐刚休长假回来，会待很久；不写她离开或回去工作。

## 七页正文

1. 江星野完成项目下楼：“项目搞定！从今天起，我是家里蹲。”
2. 江望舒拖行李回家，靠到弟弟肩上：“这次我会待很久，先把以前少陪你的时间补回来。”
3. 江辰希挽住二哥：“二哥，今天先陪我！”江望舒抱紧另一边：“我刚回来，今天先归我。”
4. 小满带着积木和故事书加入：“小叔先陪我搭城堡！”
5. 江星野拿笔排时间：“别抢，我把时间都排好了。”
6. 行程为“陪姐姐散步”“陪妹妹挑书”“陪小满搭城堡、讲三遍故事”，沈静宜补上“二弟睡觉”：“安排得很好，先把他的休息排上。”江星野：“我也有自己的行程啊？”
7. 江昭远发来消息：“老二，项目结束就好，别熬夜。”小满：“小叔休息好，就陪我讲故事！”收尾：“二弟被预约的第一天，正式开始。”

## 成品后期检查

- 所有台词、标题、手机消息、行程表和收尾字均在PNG中排版完成，用户只负责合成视频。
- 作画后统一检查光源方向、暗部层次、人物脚下与家具接触阴影，避免平涂人物悬浮。
- 人设立绘去除生硬白底，补充柔和轮廓投影和脚下阴影。
- 输出前检查人物数量、五官、对白遮挡、页面尺寸和PDF可渲染性。
