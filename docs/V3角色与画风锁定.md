# V3角色与画风锁定

## 唯一基准

- 用户确认图：`art/reference/family-character-design-v3.jpg`。
- 该图是大哥、姐姐、二弟、妹妹、小侄女五人的身份、服装、比例与画风的最高视觉基准。
- 父母在该基准的纸色、线条、低饱和色彩和人物比例下补全。
- V3不再混用V2的高饱和、粗黑漫画描边人物。

## 统一视觉

1. 暖纸底，低饱和灰蓝、米棕、灰黑与柔和肤色；不大面积切换鲜艳冷暖色。
2. 细腻、略有不完美感的手绘线，轻薄水彩式填色，自然五官与克制阴影。
3. 大哥穿深色西装；姐姐戴眼镜、低马尾、长米色外套；二弟穿深色连帽衫与灰裤；妹妹双麻花辫、米色校服开衫；小满侧马尾、叶片发饰与灰粉格裙。
4. 每页3:4、1440×1920；标题、台词、日程表、结尾文字由排版脚本绘制。
5. 原始生成画面不保留标题、姓名、标语或其他剧情文字。
6. 逐页检查人物数量、左右手、手指、面部遮挡、接触关系和脚部完整性；不得以裁切掩盖错误的手部结构。
