# 第三话｜台词自然度与"场景前置"复查（2026-11-08 第二次返修）

用户当轮意见：**"截图1这之后应该是妹妹穿上之后，才开始夸，差了一个场景"**、**"截图二是不是应该换成圣代巴菲什么的，还有台词有点怪……是不是因为一起喝之前没有场景前置"**，并要求做完后同步检查全话还有没有同类怪台词。本文件是该复查的完整结论。

## 复查方法（固定四问，逐句过）

1. **谁在说、为什么现在说？** 这句话有没有动机，还是只在描述画面里已经看得见的东西。
2. **它接住了上一句吗？** 问答是否倒置、是否答非所问。
3. **读者需要事先知道什么？** 如果这句成立的前提没画出来，就缺"场景前置"，必须补一页或改一句。
4. **同一话内是否重复到失去信息量？** 口头禅式重复可留，答非所问式重复要改。

## 一、用户指出的两处：确认成立，已改

### 1. 试衣页夸奖时序缺一个镜头（成立）

旧第3页：妹妹只把开衫**比在身前**，哥哥就已经说"很好看，这颜色很衬你"。读者看到的是"还没穿就夸"，夸奖落不到实处，也接不住"你先试，我看看"。

**改法（已实施）**：拆成两页。
- 第3页只到：妹"这件怎么样？" → 哥"你先试，我看看。" → 妹"那你不许敷衍我。"
- **新增第4页**：妹妹真的穿上浅蓝灰开衫从试衣间出来（原来的米色马甲叠好搭在手臂上，说明是试穿），哥哥这才说锁定句"没敷衍。很好看，这颜色很衬你。"，妹妹"……那我要这件。"

"没敷衍"正好回答上一页的"不许敷衍我"，跨页衔接成立。

### 2. 共饮台词怪 + 缺前置（成立，而且两个原因是同一个）

旧第6页：妹"两头吸管，正好一起喝。" / 哥"嗯，一起。"

**为什么怪**：
- 第一句只在**描述画面里已经看得见的道具**（"有两头吸管"读者自己看得到），没有动机、没有情绪、没有推进。
- 第二句"嗯，一起"是**空回声**，既不接情绪也不给信息。
- 更根本的是**没有前置**：兄妹俩为什么会共喝一杯？读者没有被给理由，于是这句台词和这个动作都显得突然、暧昧且无来由。用户的判断完全正确。

**改法（已实施）**：
- **新增第7页｜店内活动前置**：咖啡馆门口的立式看板**只画图不写字**（避免乱码假字）：一份巨型巴菲＋两把长勺 → 两个手拉手的小人 → 箭头 → 限定猫咪挂件与小手办。妹妹眼睛发亮指着看板并拉哥哥袖子，哥哥面无表情＋汗珠。
  - 妹："两个人一起吃完，就送这个挂件！"
  - 哥："……所以你才拉我来。"
- **第8页道具换成一份巨型圣代巴菲**（分层奶油、草莓、香蕉、玉米片、巧克力酱、威化棒）＋**两把长勺**，不再有饮料和吸管。
- **台词改成承载情绪而不是描述道具**：
  - 妹："一人一半……你不许笑我。"
  - 哥："……嗯，不笑。"

这样"共食一份"有了明确动机（为了限定赠品），害羞强撑也有了对象（在店里做这种双人挑战很丢脸），台词不再解释画面。

**关于"情侣活动"的取舍**：看板上的两个小人是手拉手的，读者能看出这是双人／情侣向的促销，笑点正是"妹妹为了挂件把哥哥拉进这种活动"。但**没有把画面里的兄妹本人标注成情侣**，以守住"家庭向、不恋爱化未成年"的边界。若你希望把促销明确写成"情侣限定"来放大尴尬感，可以下一轮只改看板与一句台词，不影响其他页。
