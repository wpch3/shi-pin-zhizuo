## 一、第8页画风：**合格，且「不一样却合适」是有原因的，不改**

用户说「跟前面有些不一样但是意外的合适」——这个观察成立。我先说不同在哪，再说为什么合适。

### 实测差异（并排 `shot-01.png` 锚点＋12页全览＋脸部八宫格＋色彩统计）

| 维度 | 第8页 | 其他页 | 判断 |
|---|---|---|---|
| 背景信息量 | 大面积米白墙、单盏吊灯、右侧窗框 | p5 试衣间／p6 小吃摊／p7 店门／p10 街景／p11 卧室都有密集道具与纹理 | **最大差异**，属镜头语言不是画风 |
| 线条 | 更细、更均匀、更少速写排线 | p6／p11 轮廓略粗、带速写毛边与阴影排线 | 同一「细棕线」体系内的轻重变化 |
| 构图 | 正面近景、近似对称双人半身＋水平桌面横线 | 多为斜角／全身／带景深 | 全话唯一的水平对称构图 |
| 腮红 | 密集斜线排线（hatching） | 多为柔和渐变晕染；p7／p10 也有细斜线但更淡 | 最显眼的笔触差异，但同族技法 |
| 脸型／眼型 | 略圆、眼睛略简化 | 略长、眼睛层次更多 | 锚点并排看仍是同一人设，未漂移 |

色彩/线密度统计（12 页 resize 448×600 后）：第8页 `meanRGB=192,178,165`、
`sat=31.2`（全话中位 **31.2**）、`ink=22.4%`（中位 **21.2%**）、`edge=11.1%`
（中位 **11.3%**）——**三项都贴着中位数，不是离群页**。所以「不一样」来自
构图／留白／笔触节奏，不是色调、饱和度、线密度这套画风参数变了。

`audit_page_canvas.py` 给第8页 `stroke=1.68x` 的 WARN（阈值 1.45x），但脚本自己
注明 stroke 是线宽**代理**、受大面积深色填充干扰；第8页有大块深蓝卫衣＋高留白，
代理值偏高。放大并排看线其实更细，不是变粗。结论：**WARN 已人眼复核，属代理误报，
不刷绿也不盲信**；p6(1.64x)、p9(1.53x)、p11(1.58x) 同理，均为场景明暗所致。

### 为什么「意外的合适」（判断与理由）

1. **情绪节奏需要一次呼吸**：p5→p6→p7→p10 是逛街信息密度最高的一段，第8页是
   全话情绪最高点（害羞共食）。切到留白近景，把视线压到两张泛红的脸和一只巴菲上，
   正好承接「一人一半……你不许笑我。」这种压低声音的台词。密集背景反而会抢戏。
2. **构图与台词同构**：水平桌面＋对称双人＝「一人一半」的视觉隐喻；两把长勺一左一右
   （哥哥一把、杯中一把）也在讲同一件事。
3. **近景连续**：p8 之后紧接 p9 大头照（也是双人近景特写），形成两页连续的近景段，
   再回到 p10 街景、p11 卧室，节奏是通的，不突兀。
4. **人设锚点全在**：双麻花辫、米色麻花针织背心、白衬衫领、灰蓝格裙、深蓝连帽卫衣、
   灰运动裤、细棕线、柔和渐变、暖米色底。所以是**同一画风下的镜头语言变化**，
   不是换了画风。

### 合格判定与「什么情况下才必须改」

**判定：合格，不改。** 依据：每人 2 条袖管 2 只手、桌下无任何肢体、单个高脚杯巴菲＋
恰好两把长勺、两句锁定台词与气泡归属正确（左＝妹、右＝哥）、页码 `08 / 11`、
四边铺满无框、无文字乱码、人设与画风锚点一致、150dpi 无损 PDF 逐页零差。

只有出现下列情形才必须动第8页：多余肢体／袖管、道具数量错、人设或画风系统漂移、
气泡压脸或归属错、出现画框/空白带/乱码、台词被改。目前一条都没有。
若用户以后要求「12 页笔触绝对统一」，最显眼的差异是排线腮红与留白量——但那属于
风格偏好，不是缺陷；在用户明确要求前不擅自重绘（用户本轮已明确说别改）。

## 四、本轮新增铁律（已同步 `AGENTS.md`、`PROJECT_MEMORY.md`、长期记录第十八节）

1. **交付前全项复核清单固定六类**：A 画风与风格一致性（锚点、线宽、上色、脸型、色调、
   跨页人设）；B 道具（逐页状态机、数量、跨页连续性、图标化简笔 vs 实物画法）；
   C 动作与肢体（肩线→袖管→手→道具、动作对象真实接触、时序）；
   D 台词/气泡/页码/四边/无乱码等细节；E 交付与工程事项（无损备份、轻量三件套、
   GitHub 看图、资源、增量、PR、文档-实图一致性）；F「用户会先看哪里」反向清单。
   每类必须给**结论**而非只列脚本输出；脚本 PASS 不替代人眼。
2. **画风差异 ≠ 画风漂移**：先用色彩/线密度统计与锚点并排区分「镜头语言变化
   （留白、近景、笔触轻重、对称构图）」与「画风系统漂移（人设、线稿体系、上色、
   色调）」。前者可以「不一样却合适」，要给理由，不擅自抹平；后者必须重绘。
   代理指标 WARN 必须放大目检并写明结论，禁止刷绿、也禁止盲信数值。
3. **「更正」本身也要下一轮复核**：写进文档的纠错文字同样是断言，必须对照实图。
   本轮实例：v7.1 把「直棍→勺头」改成「本来就有椭圆勺头」，两次都不属实。
4. **用户说「先判断/讨论一下」时只判断、不动图**；但「不做就会留下错误或缺陷」的
   工作仍要做，并在结论里明确区分「做了什么／没做什么／为什么」，既不偷懒也不浪费。
   判定基准：无图像改动时禁止重跑构建、重导 PDF、重建 ZIP 与轻量预览；有文档与实图
   冲突、脚本会引发无谓重写、台账与裸跑不符时必须修。
5. **封面格式铁律**：每话封面必须有本话专属大标题（黄色描边、左上、7～10 字、
   点出「谁＋什么事」），系列名只作左下角小字；不得用系列名顶替本话标题。
   标题与是否补封面台词气泡**必须用户裁定后才写入**，写入后用增量构建只重建封面页
   与派生交付，并同步文档与 PR。
6. **道具状态机与画法层级**：跨页道具生图前写状态表；图标化简笔（看板）与实物
   （第8页长勺）画法不同不矛盾，但文档不得把简笔包装成「有椭圆勺头」。
