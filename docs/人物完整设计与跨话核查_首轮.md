# 人物完整设计与跨话核查｜首轮

## 用户要求与目前边界

每个人物的相貌、身体特征、身高、身材、服饰、装饰、发型、性格、习惯动作及表情等都是人物设计的重要部分，需要具有辨识度，并在每一话保持一致。用户指出[第八话02重画候选B](../art/chapter-08-v3/scene-02-candidate-b.png)中，好友和妹妹的校服应一样：妹妹穿成深蓝上衣是明确的候选错误。

**本轮完成**：实看家庭合照、原七人独立图、主角八套已认可新造型、好友立绘、学生会两名新成员立绘、邻居姐妹及小姨的试案；从第一至八话各抽看两张实际排版页（16张）并记录。此前已逐页看过第八话v2全部页面，好友相关观察见[第八话逐页复查](../deliverables/章节/第八话/review-chapter-08-followup/逐页复查与试画.md)。本轮没有逐页复核其他各话，也没有修订已确认章节，**不能说每一话、每一页均已符合**。下方有可继续执行的逐页台账；对本轮抽样也只就列出的内容作观察，不等于整页合格。图片及判断由AI查看分析，最终以用户判断为准。

## 一、先回答：是否有设计单一的风险？

**有，但并非所有人物完全一样。** 主角人设合照中年龄与身高、眼镜、双辫、孩童比例及小满芽芽等区别清楚；八套已认可造型也区分了居家与外出，不必为了多样性推翻它们。学生会四人发色、发型和会长耳机可辨，但好友与会长立绘姿势、开衫轮廓、袜鞋、整体体型模板非常接近；活泼委员也与她们穿同款衣服，人物内在差异需要在脸、身高体态、表演等方面进一步稳定体现，而不是把共同校服改成不同制服。好友与会长对比是“轮廓与姿势相近”的观察，不推断会长已确定身材或必须与好友完全不同。

另外，多张立绘都是正面站立、手自然垂放或单一微笑，缺少侧面、背面、坐姿、常用情绪和多人同框身高参考；这会使连续作画难以稳定，但**静态立绘缺少动作参考不代表人物没有性格**。邻居姐妹是单人图，不能用画布中人物大小直接确定身高差。橙发姐妹、小姨和两位学生会新成员均待用户确认；不擅自改已认可角色。

## 五、后续执行标准

1. 按当前使用版本建立逐页角色清单，对每个出场者查身份、脸、发型发饰、年龄、身高体型、服饰鞋袜与动作表情；以角色合照、原人设及该段获认可造型为基准。旧话允许使用当时的原造型，不用后来新增的造型强行覆盖。
2. 对比邻页和同一段，换装和发型变更有可理解的时间/动作前置；同校制服锁定相同款式，好友娇小与自然丰满单独核对。按透视、人物姿态、遮挡写可见范围。
3. 制作角色补充参考时，优先补正面/侧面/背面、多人相对身高、站坐动作、自然情绪、角色惯用但已确认的表演；新设计和新增习惯须单列待用户确认。
4. 发现明确错误，记页码和证据；遮挡无法确认、风格取舍、技术适配分别记录。已确认章节先报告并征求是否改动；修订不得覆盖原文件，修后复看全页、前后页及同类页。
5. 台账中“已抽看”仅表示本轮针对人物观察过该页，**不是通过**；“未复核”表示本次尚未做专项检查。完成整个系列之前不能报告全系列符合。
