# V4第一话精细化制作记录

## 逐页剧情构图

1. **封面**：姐姐拖行李箱进门，手扶门框，回头看向家中的二弟；不再使用全身直立人设图。
2. **项目结束**：二弟完成楼上工作后自然走下楼梯，扶栏杆、伸展身体并笑着宣布解放；从工作空间回到家庭空间，衔接姐姐回家。
3. **姐姐回家**：姐姐自然靠肩并挽住前臂，二弟拿着杯子露出无奈笑意，行李箱留在门边。
4. **姐妹争人**：姐姐与妹妹向相反方向轻轻拉人，二弟失去平衡，动作和表情形成喜剧关系。
5. **小满加入**：二弟蹲到小满视线高度，小满面向小叔、拿积木邀请，姐妹在后方反应。
6. **亲自安排**：四人围桌，二弟写日程，姐姐扶椅俯看，妹妹指日历，小满站在地面拿书。
7. **妈妈加一项**：母亲拿笔并把休息用品推给二弟，二弟抬手抗议；完整日程排入下方区域。
8. **结尾休息**：姐姐给二弟盖毯，小满在地毯上跪坐并举书；手机表示外地大哥的消息，大哥本人不出现。

- 第2、3、4、7页原画中的空白框已通过画面清理移除，获得无框底图；不再使用矩形色块擦除，因此无白色补丁、旧边线或原气泡残留。
- 全部普通对白统一为暖白圆角气泡；手机消息单独使用深色气泡，不再混用裸字、方框、椭圆或云形。
- 黄色解析标题仅保留在封面及结尾，第1—7页不再逐页添加解释性黄字。
- 第3页姐妹台词已放入各自统一气泡，不压人物面部。
- 第4页小满台词已移入左侧气泡。
- 第5、6页撤销旋转贴字和补色多边形，改为完整文字块透视映射到纸内，保留纸边与安全边距。第6页旧格线与目标栏位不一致，最终先清除格线取得空白纸，再排统一单栏日程，避免跨线和拼接。
- 所有对白气泡的小三角均补上与框体一致的描边，并校正封面、第1、2、5、6页尾巴方向，使其朝向实际说话者。
- 第7页大哥消息改为无尾巴的“妈妈转述”框，避免误指沙发上的二弟；小满气泡移至下方居中，以向上尾巴指向小满，不压任何人物头部。
- 最终逐页复查：大哥仍只由母亲转述，人物数量、姐妹及小满台词归属正确；日程均在纸内，页码和结尾条无重叠。

- 第4页再次清点肢体后移除小满第三只手及多余手臂，仅保留胸前拿积木和伸向二弟的两只手，补全袖口连接。
- 第6页收敛二弟的惊讶表情，改为略睁眼、微张嘴并带一点无奈，避免日常对话中瞪眼大喊的过度表演。
