# 漫画返修流程与验收表

## 一、强制流程

### 1. 台词锁定

- 逐句确认说话者、先后顺序、动作和语气。
- 画面内人物普通对白不写姓名标签；画外来源可以标注。
- 二弟少话不等于机械敷衍；没有说话动作不硬加对白。

### 2. 文字分镜

每页先做低精度布局稿，至少包含：真实台词、预计分行、椭圆气泡范围、人物头口位置、尾巴方向、镜头和阅读箭头。此步通过后才能精画。

### 3. 表情与动作草图

- 把台词念出来，对照角色眉眼、嘴、身体和视线。
- 二姐独占、耍赖、俏皮时不能冷脸训斥。
- 日常惊讶不能暴眼大喊；肢体和接触关系必须正确。

### 4. 原画与气泡共同构图

- 不生成“顶部一整块随机白纸、下面才是漫画”的模板图。
- 气泡可以覆盖不重要背景，人物不必为了躲气泡被挤到页底。
- 横向分镜线只有在确实分镜时使用。

### 5. Lettering精排

- 先测文字，后生成贴合的椭圆。
- 文字视觉居中，四边余量均匀；正文风格统一。
- 尾巴从气泡重心一侧指向嘴部，短、清楚、不交叉、不切线。
- 每页坐标独立，不使用统一顶部四角作为最终位置。

### 6. 整页目检

同时看1440×1920阅读版、1440×2146竖屏版和手机缩放效果。检查的不是是否“像一张漂亮插画”，而是是否“作为一页漫画读得顺”。

### 7. 成品与视频

重建两话全部受影响页面及PDF；视频用真实成品。导出后读取MP4元数据并抽帧，确认宽高、SAR、DAR、字幕和气泡。

## 二、每页验收表

每页必须逐项打勾，任何“不适用”都要写明原因。

- [ ] 页面叙事目的明确，人物、动作和台词服务同一件事。
- [ ] 普通对白使用椭圆或略椭圆气泡；矩形只用于确有需要的caption或消息。
- [ ] 不看姓名标签也能确认每句是谁说的。
- [ ] 阅读顺序第一次就能看懂，无需来回跳。
- [ ] 气泡靠近说话者，尾巴短而明确，指向嘴部或明确声源。
- [ ] 尾巴不交叉、不跨他人脸颈、不指向空处，不与轮廓形成难看的相切。
- [ ] 文字视觉居中、字号统一、余量均匀，无孤字、孤标点、贴边或大面积无效内部空白。
- [ ] 气泡不遮脸、手、关键动作、道具和人物接触。
- [ ] 表情、嘴型、动作、视线与台词一致。
- [ ] 没有无叙事作用的大块空白、虚假横线或“上图下画”拼接感。
- [ ] 暖色低饱和、人物发型服装和画风一致。
- [ ] 1440×1920阅读版和1440×2146竖屏版内容一致，竖屏没有拉伸或16:9黑边。
- [ ] 最终手机尺寸下仍可读，尾巴仍可见，人物表情仍能辨认。
- [ ] 已打开真实输出图片检查，而不是只看代码或构建日志。

## 三、整话验收表

- [ ] 两话16页分别检查，不是抽查一页代表全部。
- [ ] 相邻页气泡样式统一，但位置与构图不机械重复。
- [ ] 对话节奏有疏密，不每页都堆同样数量、同样大小的框。
- [ ] 所有普通对白无角色名标签依赖，画外来源仍明确。
- [ ] 封面由该话主角担当，标题、定句、人物和气泡形成统一焦点。
- [ ] 第二话说明、旁白、结尾均为第三人称；第一人称只出现在对白。
- [ ] 亲情互动不恋爱化、不惩罚化、不屈辱化。
- [ ] 两话PDF页数正确，且逐页目检通过。
- [ ] 视频与最终漫画页一致，无旧帧、错页或错误画幅。

## 四、交付记录格式

每次返修提交不能只写“优化排版”，至少记录：

1. 修改了哪些页；
2. 原画是否变化，变化原因是什么；
3. 气泡、文字、尾巴和阅读顺序如何变化；
4. 哪些页面仍需重画；
5. 实际查看了哪些输出文件；
6. 尚存问题，不得用“全部完美”掩盖。
