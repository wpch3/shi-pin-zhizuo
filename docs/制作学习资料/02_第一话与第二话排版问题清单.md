# 第一话与第二话排版问题清单

审查对象：`deliverables/full-v4-vertical/chapter-01/` 与 `chapter-02/` 的返修前正式输出，以及对应1440×1920阅读版。以下记录用于追溯已确认问题，不代表返修已经完成。

**进度更新：第一话已于2026-11-08完成系统返修和整话复检；第二话随后也完成系统返修和整话复检。两话原有固定圆角矩形、顶部四角坐标、大白板、假横线及指定表情动作问题不得回退。**

## 一、两话共同根因

| 根因 | 当前表现 | 后果 | 必须改变 |
|---|---|---|---|
| 原画阶段没有真实文字与气泡草图 | 生成时只要求“上方留白”，完成后用固定脚本塞框 | 人物与对白互不参与构图 | 先排文字与粗气泡，再定人物与背景 |
| 所有普通对白用固定圆角矩形 | 大框、左上角色名、短句也占很大面积 | 像聊天界面，不像漫画 | 按文字量生成椭圆；画面内说话者取消姓名标签 |
| 固定顶部四角坐标 | 无论人物在哪，气泡都在页面顶端 | 气泡远离嘴部，短尾巴只指空气 | 每页独立设置气泡与头口锚点 |
| 尾巴过短 | 气泡距人物数百像素，尾巴只延伸约二十余像素 | 归属依赖角色名，不靠画面 | 尾巴清楚指向嘴部，通常覆盖约一半距离；过远时重构气泡位置 |
| 横线被当作版式装饰 | 一个场景被切成顶部白色区和下部人物区 | 像文字框与插图拼接 | 非真实分镜边界必须去除 |
| 只检查文件、尺寸与明显身体错误 | 技术导出通过就宣布完成 | 表情、阅读动线、空白和气泡问题反复遗漏 | 最终尺寸逐页目检并做隐藏姓名测试 |

## 四、返修优先级

1. **先修流程与排版组件**：动态测量文字、椭圆气泡、正确尾巴、逐页锚点；不得只替换圆角为椭圆。
2. **先处理第二话第1页表情**：这是用户明确指出的独立创作错误，排版修复不能代替。
3. **同步重构两话顶部白色分区**：涉及原画或镜头时真实重画/修图，禁止只铺白色或拉伸人物掩盖。
4. **逐页返修而非批量套坐标**：每页台词、人物、视线、气泡和尾巴分别检查。
5. **重建阅读版、竖屏版、PDF和视频**：视频必须保持1440×2146，导出后检查实际帧，而非只看工程配置。

## 五、禁止的“假修复”

- 只把矩形换成椭圆，位置、距离、空白和尾巴原样保留。
- 继续依赖左上角姓名标签掩盖错误归属。
- 用一条更长更尖的尾巴跨越半页寻找人物。
- 把气泡、横线或大空白解释成“漫画风格”而不做阅读检查。
- 用裁切遮掉表情或手部结构错误，用拉伸填满空白。
- 在表情不对的原画上重新排字后宣布全部解决。
- 只检查PDF页数、像素尺寸、构建成功，不打开真实图片目检。
