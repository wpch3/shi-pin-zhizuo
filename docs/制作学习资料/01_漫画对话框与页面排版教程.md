# 漫画对话框与页面排版教程

> 依据：Comicraft术语与操作建议、Clip Studio Paint漫画排版教程、Evan Waterman lettering指南、Karen Gillmore漫画 lettering教学。原始链接见 `04_外部教程与参考资料.md`。本教程把资料转化为本项目的执行步骤，不把任何经验值当成脱离画面的机械公式。

## 一、先区分对白、旁白和消息

- **普通人物对白**：使用圆形或略椭圆形、轮廓平滑的对白气球，配一条明确尾巴。
- **内心思考**：通常用云形气球与小圆点尾巴；本项目目前没有，不得误用。
- **喊叫**：才使用爆破形；日常家庭对话不能使用爆破或夸张大嘴。
- **旁白、时间地点、结尾说明**：可以使用矩形caption，不加人物尾巴。
- **手机或画外消息**：可使用区别于普通对白的样式，但必须说明来源，不能让它误指画面人物。

当前两话把所有普通对白放进圆角矩形并加角色名，像聊天软件界面，不像漫画对白。正式返修时，画面内说话者不再重复写姓名标签，靠位置和尾巴明确归属；画外人物才保留来源标识。

## 二、文字先于气泡，气泡先于精画

正确顺序：

1. 定稿这一页谁先说什么、谁回答、谁只做动作。
2. 测量文字并决定分行，不能先画固定大框再塞字。
3. 在缩略图中放入粗略气泡，确定大小、顺序和尾巴。
4. 根据气泡位置安排人物头部、动作、镜头和背景留白。
5. 完成原画后，只微调气泡，不推翻阅读动线。

Clip Studio教程明确建议分镜阶段就放粗略气泡，Liz Staley甚至会在画人物前先放文字，以确定实际占用空间。当前流程是“先让模型随机留一块顶部空白，再按固定坐标填框”，顺序相反。

## 三、普通对白气泡的形状与文字余量

- 气泡应贴合文字块，是椭圆或略有机的椭圆，不是统一宽高大圆角框。
- 中文正文统一字号与行距；文字块在气泡内视觉居中，不能固定靠左上。
- 文字到轮廓保留均匀余量，Comicraft以约一个字符宽为经验值。短句不能沿用长句的大框。
- 多行文字尽量中间宽、上下略窄，形成均衡块面；避免最后只剩一个标点、一个短词或一个孤字。
- 不为缩小气泡而挤压文字、缩小字号；应先缩短台词或合理分行。
- 普通气泡的字号、轮廓粗细、尾巴根部粗细和内部余量保持一致。特殊语气才可有意变化。

## 四、阅读顺序

本项目采用中文从左到右、从上到下：

- 第一句通常先进入左上或视觉起点；下一句沿清楚路径继续，不让读者来回跳。
- 多人同页时，气泡顺序必须与台词先后一致，不能只按哪里空就放哪里。
- 左右站位是辅助，不是唯一标准；必须同时看阅读顺序、人物位置和尾巴。不能为“左左、右右”把答句排到问句之前。
- 尾巴不得交叉，不得穿过另一角色的脸、脖子或关键动作。
- 同页短对话应靠得足以表示接续，但不能挤成一块；过远会切断交流，过近会变成抢话。

## 五、气泡与说话者的距离

- 普通对白气泡放在说话者头口附近的安全区域，优先利用脸旁、肩上、人物之间的自然空白。
- Comicraft建议尾巴指向嘴部，而不是泛指头、胸、手或空处；通常延伸约气泡到嘴部距离的一半。Evan Waterman也提醒避免过长尾巴。
- 气泡不能为了“不遮画”退到页面最顶端，再用一小截三角敷衍指向。正确做法是重新安排镜头和气泡位置。
- 不遮眼、嘴、表情、手、接触关系和关键道具。可以覆盖不重要的背景，不能为了保全部背景而牺牲归属。
- 避免气泡边线与门框、家具、人物轮廓形成相切；看似接上的切线会让画面僵硬。

## 六、留白不是空白仓库

有效留白：引导视线、给对白空间、表现安静、突出人物或形成节奏。

无效留白：没有构图目的的大块纯色、与说话者距离遥远的顶部区域、由模型自动生成的白色分区、气泡内部过多空余。

检查方法：

1. 把气泡暂时隐藏，观察空白是否仍有叙事作用。
2. 把气泡放回，观察人物、气泡是否属于同一个场景，还是“上图下画”。
3. 检查人物是否被挤到下半页，头顶空间是否远大于构图需要。
4. 用最终手机尺寸检查，而不是只看桌面大图。
5. 若大块空白无作用，优先重构镜头、调整人物占比或重画；不得靠增加标题、装饰或更多对白填满。

## 七、分镜线与页面边界

- 一条横线代表真实分镜边界时才有意义。
- 单页单场景不应被随机横线切成“文字层”和“插图层”。
- 分镜边框与气泡轮廓要协调，不能让横线、尾巴、门框形成错误连接。
- 同一页若确实需要两个时刻，应明确分成两个构图，各自拥有动作与视线，而不是一块空白加一块人物图。

当前多页的顶部横线来自生成提示中的“上方留白”，不是剧情分镜，应在返修时去除或通过重新构图消除。

## 八、表情与台词是一体排版

- 说话者的嘴、视线、眉眼必须与台词同时成立。
- 二姐俏皮独占、耍赖时，不能面无表情或严肃像训斥。
- 二弟口误可以小幅停顿，不能眼球暴突；二弟少话不等于全程无反应。
- 动作也必须一致：合电脑就是合电脑，洗衣就是洗衣，抱睡就是抱睡。
- 角色嘴型不自然、表情与语气不符时，应先修原画，再排字。气泡不能承担表情缺失的解释工作。

## 九、本项目返修时的页面数据结构

每页必须先写明以下信息，再进入绘制：

- 页面叙事目的；
- 镜头与人物占比；
- 每个说话者的头口大致位置；
- 每句台词的顺序、文字块和气泡预计范围；
- 每条尾巴的起点、方向与终点；
- 不重要的可覆盖背景区；
- 必须保护的脸、手、道具和视线；
- 表情与动作验收句；
- 手机尺寸下的阅读路径。

固定统一的气泡矩形和统一四角坐标不再作为正式排版方法。

## 十、最终验收

- 不看姓名标签，能否仅凭画面和尾巴判断谁在说？
- 第一眼是否按正确顺序读完？
- 气泡是否靠近说话者，尾巴是否短而明确？
- 文字是否居中、余量均匀、无孤字孤标点？
- 普通对白是否统一椭圆，旁白与消息是否另有明确用途？
- 是否存在无作用大空白或虚假横线？
- 表情、嘴型、动作、视线是否支持台词？
- 在手机尺寸下，文字、人物和对话关系是否仍清楚？

任何一项回答“不确定”，都不能宣布完成。
