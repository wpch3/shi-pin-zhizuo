# 漫画制作学习资料区

本目录保存经过外部教程核对、并转化为本项目可执行规则的制作资料。它不是为了堆链接，而是为了纠正当前两话反复出现的对话框、留白、分镜和表演问题。

## 文件索引

1. [漫画对话框与页面排版教程](01_漫画对话框与页面排版教程.md)  
   普通对白形状、文字测量、气泡余量、阅读顺序、人物归属、尾巴、留白、分镜和手机检查的完整操作方法。

2. [第一话与第二话排版问题清单](02_第一话与第二话排版问题清单.md)  
   对当前16页逐项记录问题、根因、返修级别和验收要求。清单中的“待返修”不得当作已完成。

3. [返修流程与验收表](03_返修流程与验收表.md)  
   从文字分镜、缩略图、原画、表情、排版到视频导出的强制顺序，以及每页必须通过的检查。

4. [外部教程与参考资料](04_外部教程与参考资料.md)  
   Comicraft、Clip Studio Paint、Evan Waterman、Karen Gillmore等原始资料链接和本项目采用的要点。

## 当前强制结论

当前两话的圆角矩形大气泡、远离说话者的短尾巴、顶部大空白与横向分割，不是可以忽略的“风格选择”。普通对白必须改为按文字量生成的椭圆气泡；所有页面必须重新检查构图和对话区域，不能只把旧气泡改成椭圆就宣布返修完成。
