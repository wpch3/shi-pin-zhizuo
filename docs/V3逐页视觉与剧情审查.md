# V3逐页视觉与剧情审查

> 最高长期记忆见项目根目录 `PROJECT_MEMORY.md`。每次制作前必须先读该文件；本清单与其同时执行。

## 禁止冒充完成的三条红线

1. **人设立绘＋标题＋对话框，不是漫画封面。**封面必须依据剧情独立构图、独立绘制。
2. **旧原图＋方对话框，不是精细化正片。**每页必须重新设计动作、表情、镜头、人物关系、场景与对白构图。
3. **脚本运行、文件生成、尺寸及页数正确，只代表技术校验通过，不代表作品合格。**未逐页目视和剧情审查，不得交付。

## 永久审查铁律

每次交付前，不仅检查文件能否打开，必须逐页完成以下三类判断；任何一项不通过就修改或重做，不直接交付。

### 一、用眼睛检查画面

- 人物数量是否正确，有无重复人物、额外肢体、错误左右手、粘连手指。
- 头、脸、手、脚是否完整；对白框和标题是否遮挡五官或关键动作。
- 身体朝向、视线、手势、站姿、坐姿是否符合动作目的，是否扭转不自然。
- 接触关系是否明确，人物与地面、沙发、桌面是否有合理接触和阴影。
- 是否有模型擅加的文字、标志、无意义线条、残留背景或微瑕。

### 二、对照基准检查画风

- 与 `art/reference/family-character-design-v3.jpg` 对比线条粗细、填色、脸型、发型、年龄感和服装。
- 全话统一暖纸底、低饱和灰蓝米棕、细腻手绘线和克制阴影。
- 不得某一页突然变成厚水彩晕染、 油亮AI高光、粗黑赛璐璐或不同人物比例。
- 正确部分保留，不为了“观感”随意改变已确认风格。

### 三、用大脑核对剧情

- 人物此刻是否在家、是否该出现，是否与出差、休假等状态冲突。
- 台词由谁说、对谁说，动作能否表达该句台词。
- 亲属互动是否符合家庭关系；小满保持儿童日常互动。
- 日程、标题、结尾是否与前页因果一致，不让画面擅自增加设定。
