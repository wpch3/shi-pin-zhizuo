# 《大哥以前，也只是个孩子》七话章节规划

- **形式**：大哥江昭远的独立故事线，按话数制作。
- **篇幅**：暂定7话，每话8—10页，共约56—70页。
- **时间跨度**：镇上童年、十三岁患病、两年治疗、复学、拒绝警校安排、工程学院、民企、国企、项目总经理及当前家庭生活。
- **核心主题**：他不是因为是大哥才必须扛住一切，而是因为曾经被家人接住，所以也想成为能够接住家人的人。

## 第一话：镇上的第一个孩子

**本话曲线：平凡幸福的童年 → 十三岁突然病倒。**

- 父母还在镇上，没有出去打拼，家里物质条件普通。
- 昭远是家里的第一个孩子，没有像后面的兄弟姐妹那样见过很多东西。
- 他每天玩得很开心，学习也认真；可画田埂、弹珠、书包、作业等具体生活细节。
- 不把他过早写成没有童年的“小大人”，他首先是一个普通孩子。
- 反复发烧、皮肤焦黄，最初被当成普通身体不适。
- 他趴在书桌上，母亲发现脸色异常。

**结尾钩子**：区医院医生把父母单独叫进办公室。

## 第二话：爸妈不肯认命

**本话曲线：区医院没有办法 → 父母带他去市医院。**

- 父母不肯接受“没办法”，收拾病历和生活用品，带孩子去市医院。
- 昭远仍惦记退烧后的学习和考试，以孩子的期待对照病情。
- 市医院重新检查和住院，治疗变成漫长的往返。
- 家庭积蓄、父母工作与孩子治疗之间出现现实压力。
- 父母开始外出打拼，既有生活变化，也有支撑家庭的需要。

**结尾钩子**：治疗刚有起色，昭远再次发起高烧。

## 第三话：两年，终于回家

**本话曲线：漫长治疗 → 痊愈 → 复学后的落差。**

- 用季节变化、车票、药袋、医院走廊和父母轮换陪护表现两年，不重复单一病床画面。
- 治疗有希望也有反复，最终治好，没有多少后遗症。
- 一家人回家，昭远以为只要补回落下的课程就能恢复从前。
- 他发现自己理解、背诵和集中注意力都变得更吃力。
- 曾经成绩很好的他第一次面对很低的分数，把试卷藏起来。

**结尾钩子**：父亲说：“实在学不下去，就不学了。”

## 第四话：我不去警校

**本话曲线：父亲给出退路 → 昭远拒绝 → 坚持但并未逆袭。**

- 父亲在外已有成就，提到警校的位置还留着，希望他不必继续受苦。
- 父亲不是阻挠者，昭远也不是为了反抗而反抗；两人是在不同角度心疼彼此。
- 昭远认真考虑后说不想去，选择继续读下去。
- 他的成绩仍一年不如一年，从被老师重点期待逐渐成为普通学生。
- 最终考上工程学院，不写成突然成为尖子生的爽文逆转。

**结尾钩子**：毕业前，父亲提出可以帮他安排工作，他再次拒绝。

## 第五话：不从家里借台阶

**本话曲线：毕业独立 → 民企基层 → 学会真正的责任。**

- 自己投简历、租房、进入民企，不依靠父母安排。
- 他并非天生管理人才，会犯错，也不懂复杂职场规则。
- 只会埋头做事让他碰壁，使他认识到努力不等于已经会做工作。
- 在项目失误、沟通、带人和承担责任中逐渐成长。
- 获得升职机会后，他仍选择寻找更适合自己的长期平台。

**结尾钩子**：拿到国企岗位录用通知，但需要从头证明自己。

## 第六话：从民企到国企

**本话曲线：重新起步 → 具体项目证明能力 → 成为总经理。**

- 民企经验不能直接解决国企中的所有问题，他必须重新学习。
- 用具体项目、团队选择和责任承担表现晋升，不用空泛蒙太奇跳过。
- 他逐渐成为沉稳可靠的管理者，也更加习惯不轻易向家里诉苦。
- 重要项目中不向下属推卸责任，凭实际能力获得信任。
- 最终成为项目总经理，但职位不是全系列最大的情绪终点。
- 回家看望父母时，母亲发现他仍像生病时一样不肯让人担心。

**结尾钩子**：二弟发来消息：“哥，项目刚结束，最近有点累。”

## 第七话：现在，轮到我接住他们

**本话曲线：回应主线 → 明白可靠不是硬撑 → 人物弧光完成。**

- 大哥没有让二弟“扛一扛就过去”，而是提醒他休息。
- 他想起十三岁时父母没有放弃自己。
- 他明白可靠不是永远硬撑，而是在家人需要时能够接住对方。
- 与小满视频时，从严肃的项目总经理变成温柔的爸爸，回扣女儿控设定。
- 不要求弟弟妹妹复制自己的路，希望他们也能选择自己的生活。
- 回到镇上的旧照片：当年被父母拉住的孩子，如今能站在家人身后。

**系列落点**：曾经被家人接住的人，如今也成为了能够接住家人的人。

## 与主线的连续性

- 大哥当前在外地工作、出差，第一话正片不让他无故现场回家。
- 他对二弟“别熬夜”的关心可以由母亲转述，也可以在后续通过手机、视频或回家章节表现。
- 大哥的婚姻与小满母亲等未确认设定，不因本系列擅自补写。
- 父母外出打拼的时间、警校安排的具体年份及工作经历，在正式分镜前可进一步细化，但不得改变用户原始故事的核心选择。
