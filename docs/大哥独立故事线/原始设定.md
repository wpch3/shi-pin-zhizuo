# 大哥独立故事线｜用户原始讨论原文

> 本文逐字保留用户提出的故事构想，作为后续创作的原始依据。文字中的用词、语序及输入痕迹均不擅自改写。

我们先讨论一件事情，我认为大哥之后可以有个独立的故事线：作为家里的第一个孩子，那个时候爸妈还在镇上，没有出去打拼，从小也没有像后面的兄弟姐妹那样见过很多东西，但是明天都玩的很开心，学习也很认真，直到十三岁，他换上了肝炎，不断发烧，皮肤焦黄，去区医院医生都说没办法，爸妈不肯信这些，带着他去市医院去医，来来回回医了两年，终于医好了，没有多少后遗症，只不过他发现一件事情，之前成绩非常好的他，学习变得毕竟困难了，爸爸这时候也在外面有些成就了，所以也在跟他说学不下去就不学，前两年警校的说位置还给它留着的，但是他说他不想去了，他就继续读了下去，之后成绩一年不如一年，但是还是考上了工程学院，毕业之后不靠父母，他想自己拼搏，一路从民企走到国企，到现在的总经理...这个故事你觉得如何适合单独做出来吗？

## 讨论结论

- 适合单独制作，而且不应压缩成十二页的人物小传。
- 采用按话数计算的独立章节系列，当前规划为七话，每话约8—10页，总计约56—70页。
- 故事不做单纯的“患病后逆袭当上总经理”，重点是人物被家人接住、成长后又接住家人的过程。
- 核心表达：**一个曾经被父母拼命拉住的孩子，长大后也想成为能够接住家人的人。**
- 医学细节以人物经历为主，不把学习困难直接写成肝炎必然造成的医学结论；可表现落下课程、恢复期疲劳、注意力和记忆感受等叠加影响。
- 警校是父亲后来提供的一条现实退路，不是父子冲突的反派安排；父亲心疼他，大哥则认真作出自己的选择。
- 成绩不会因为他决定努力就突然逆袭，仍然一年不如一年，最后考上工程学院，使坚持更真实。
- 事业线需要具体项目和选择，不用“多年后成为总经理”一句话跳过。
- 系列最后回扣主线：大哥提醒二弟“项目结束就好，别熬夜”，因此具有他自己经历过的分量。
