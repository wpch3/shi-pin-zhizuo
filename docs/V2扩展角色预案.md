# 女性扩展角色预案（仅规划，不进入当前正文）

> 本项目本质为家庭向“爽文”。所有新增女性角色都必须对江星野具有明确好感，但好感可按亲属疼爱、晚辈崇拜、朋友欣赏、同事信任或成年恋爱好感区分，不把所有关系写成同一种模式。
>
> 当前只做人设与剧情功能规划，**不加入第一话或其他当前正文，不进入七人合照，不挤占原七人的戏份**。正式启用某名角色时，需先取得用户确认，再制作对应独立人设和当期封面。

## 1. 林知夏｜江辰希的同班同学

- **定位**：妹妹亲近的同学，成绩优秀，性格爽朗，擅长摄影与校园活动策划。
- **对江星野的好感**：因辰希认识星野后，明显喜欢并崇拜这位可靠、会照顾人的哥哥；羡慕辰希，愿意主动接近江家。她是未成年人，只写晚辈式崇拜和亲近，不写与成年二弟的恋爱关系。
- **剧情功能**：打开妹妹校园线，证明辰希在外独立能干，只在二哥面前撒娇。
- **适用章节**：复习、选书、校园活动、合照冲印等妹妹主场。
- **视觉方向**：与辰希不同的高马尾或短发、便服和相机包。

## 2. 沈静岚｜沈静宜的妹妹（小姨）

- **定位**：母亲一方的成年亲属，干练爽快，经营花店或咖啡店，与姐姐关系亲密。
- **对江星野的好感**：看着星野长大，明确偏爱、欣赏和信任他，喜欢逗他，遇到事情也愿意站在他这边；属于长辈式疼爱，不写暧昧关系。
- **剧情功能**：连接母亲娘家、父母镇上时期及大哥童年治疗经历，能提供其他家庭成员不知道的往事。
- **适用章节**：家庭聚餐、节日送花、大哥独立故事线或母亲主场。
- **视觉方向**：暖色穿搭、短卷发或低马尾，花店围裙作为标志道具。

## 3. 姐姐的同事或闺蜜｜姓名待定

- **定位**：与江望舒能力相当的成年职场女性，做事利落，了解姐姐过去工作的真实情况。
- **对江星野的好感**：接触后明确欣赏星野的生活能力、责任心和照顾家人的方式，愿意主动创造见面机会；可保留成年好感的发展空间。
- **剧情功能**：展示姐姐在外精明能干的反差，也能解释她过去缺席陪伴的原因，而非把姐姐写成工作机器。
- **适用章节**：姐姐职场交接、闺蜜来访、姐姐休假期间的聚会。
- **视觉方向**：与姐姐的米色长外套区分，采用更利落的短发或职业套装。

## 4. 二弟的女性工作搭档｜姓名待定

- **定位**：与江星野能力相当的成年项目搭档，有独立事业目标和专业能力，不是等待男主帮助的陪衬。
- **对江星野的好感**：在长期合作中明确欣赏并信任他，随着项目推进产生成年女性主动、可见的好感；在爽文节奏中可成为明确的感情候选人之一。
- **剧情功能**：打开二弟职场线，表现他的专业能力和可靠，而不只局限于家中被争抢。
- **适用章节**：新项目、危机处理、庆功或工作搭档来家中谈事。
- **视觉方向**：与姐姐、妹妹都不相同的职场休闲造型和项目道具。

## 启用与爽文原则

1. 所有新增女性必须对江星野有好感，并在台词、选择或行动中实际表现，不能只写在设定里。
2. 好感不能替代人物功能；每名角色必须打开新场景或展示主角不同的一面。
3. 不设置无意义的雌竞或恶意女性反派来拖慢爽文节奏；冲突来自时间安排、生活事件和不同关系需求。
4. 每次优先启用一名，避免多名新角色同时争夺篇幅。
5. 新增角色不能替代姐姐、妹妹、小满及母亲的既定位置。
6. 当期谁是主角，谁就拥有独立剧情封面；新增角色正式成为主角时才制作对应封面。
