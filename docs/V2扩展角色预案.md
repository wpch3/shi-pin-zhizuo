# V2 扩展角色预案

> 本文件仅作后续备选。以下角色**不进入第一话正文**，不挤占江家七人的戏份，也未纳入当前人物合照。

## 林知夏｜江辰希的同班同学

- **定位**：妹妹亲近的同学，成绩优秀，性格爽朗，擅长摄影与校园活动策划。
- **与江星野的关系**：因辰希而认识星野，把他当作可靠、会照顾人的哥哥；欣赏他做事认真、说话算数，不写成未成年人恋爱线。
- **与七人主线的连接**：可带校园活动、选书、合照冲印等事件回家，让辰希在同学面前能干独立、回家后才对二哥撒娇。
- **后续功能**：提供妹妹校园生活的观察者视角，不介入家庭内部矛盾。
- **视觉方向**：与辰希不同款的短发或高马尾、便服与相机包，避免复制校服妹妹的轮廓。

## 沈静岚｜沈静宜的妹妹（小姨）

- **定位**：成年人的家庭亲友，干练爽快，经营花店或咖啡店，与姐姐沈静宜关系亲密。
- **与江星野的关系**：看着星野长大，欣赏他的责任心和生活能力，喜欢逗他、也愿意帮他；是长辈式的亲近和认可，不写暧昧关系。
- **与七人主线的连接**：节日送花、家庭聚餐、临时送点心时短暂登场；能看出母亲的温和精明，也能替大哥传递对二弟工作的关心。
- **后续功能**：扩展母亲一方的亲情网络，提供家庭之外的生活场景。
- **视觉方向**：与母亲相近但不相同的暖色穿搭、短卷发或低马尾，花店围裙作为道具。

## 启用原则

1. 新角色必须通过具体事件自然登场，不能用长篇介绍打断第一话。
2. 每次只启用一名，仍围绕江星野与七位家人的关系推进。
3. 新角色可以喜欢、亲近或欣赏江星野，但不能替代姐姐、妹妹、小满等人的既定位置。
4. 正式启用前须另做V2标准图、表情与服装规范，并取得用户确认。
