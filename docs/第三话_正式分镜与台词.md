- 江星野外出：深蓝连帽卫衣、灰裤、运动鞋；家居：浅灰长袖T、深灰蓝宽松睡裤、灰拖鞋。第4页正装为服装店试穿，不改变后续外出服。
- 江辰希外出：奶白泡泡袖衬衫、浅米针织马甲、灰蓝格纹百褶裙、深棕小皮鞋、米色斜挎包；家居：浅米粉小翻领纽扣纯棉睡衣、白袜。
- 江望舒结尾：燕麦色针织家居套装、圆眼镜、低马尾、米色拖鞋。
- 小满：浅杏色小熊印花法兰绒睡衣、白袜、叶片发饰侧马尾。
- 饮料道具：**一杯饮料 + 一根Y形双头吸管**。只有一个杯身、一个液面、一个吸管入口组件；上端分成两个可入口吸管头，两人各含一个。不得画成两杯、两根独立普通吸管或两个互不相连的道具。

## 逐页分镜与正式台词

### 封面
- 画面：妹妹外出服独立街景构图，前景明亮笑容、和平手势并轻拉哥哥袖口；哥哥在后景提袋陪伴。
- 文字：只使用系列名《二弟的休息日被全家预约了》与“第三话”。
- 台词：无。

### 第1页｜七点叫起床
- 画面：清晨卧室，哥哥在床上困倦，妹妹家居服在床边指闹钟/拉被角，闹钟7:00。
- 妹妹：“二哥，七点啦！说好今天陪我逛街的。”
- 哥哥：“……起，给我两分钟。”

### 第2页｜收拾出门
- 画面：玄关，妹妹外出服已就绪回头催促，哥哥外出服提袋跟上。
- 妹妹：“收拾好了，出发！”
- 哥哥：“嗯，走吧。”

### 第3页｜买衣服试衣服：真心夸奖
- 画面：服装店，妹妹拿浅蓝开衫在身上比划，哥哥认真看，不敷衍。
- 妹妹：“这件怎么样？”
- 哥哥：“你先试，我看看。”
- 妹妹：“那你不许敷衍我。”
- 哥哥：“没敷衍。很好看，这颜色很衬你。”

### 第4页｜买衣服试衣服：正装惊艳
- 画面：哥哥从试衣间出来，正装合身；妹妹短暂愣住、眼睛亮起来。
- 妹妹：“哇……二哥，你穿正装这么帅的吗？”
- 哥哥：“嗯，走吧。”

### 第5页｜一起吃美食
- 画面：小吃街/餐桌，妹妹递一口食物给哥哥，哥哥尝。
- 妹妹：“这个好吃，你尝一口。”
- 哥哥：“嗯，不错。”
- 妹妹：“那再给我留一点。”

### 第6页｜一杯两头Y形吸管
- 画面：同一杯饮料与双人中景，Y形双头吸管结构清楚，两人各含一个吸管头。
- 妹妹：“两头吸管，正好一起喝。”
- 哥哥：“嗯，一起。”

### 第7页｜拍大头照
- 画面：大头照机前，妹妹拉哥哥靠近，屏幕/取景框可见两人。
- 妹妹：“靠近一点，看镜头！”
- 哥哥：“这样？”
- 妹妹：“对，笑一下嘛。”

### 第8页｜女同学疑问与指定回答
- 画面：妹妹抱着哥哥手臂；妹妹女同学在场并先疑问。哥哥不吐槽、不解释。
- 女同学：“这位是……？”
- 妹妹：“这个是我男朋友。”
- 禁止：任何“这是我哥”、误会澄清、哥哥吐槽、同学继续追问。

### 第9页｜回家同睡与姐姐带侄女上床
- 画面：哥哥床上妹妹与哥哥已躺下/盖被；姐姐回家看到吃醋，带小满也爬上床。哥哥不接话，以动作容纳。
- 姐姐：“我才回来，位置就被你们占完了？”
- 小满：“小叔，我也要！”
- 姐姐：“走，小满，我们一起。”
