## 逐页分镜与正式台词

### 封面
- 画面：妹妹外出服独立街景构图，前景明亮笑容、和平手势并轻拉哥哥袖口；哥哥在后景提袋陪伴。
- 文字：只使用系列名《二弟的休息日被全家预约了》与“第三话”。
- 台词：无。

### 第1页｜七点叫起床
- 画面：清晨卧室，哥哥在床上困倦，妹妹家居服在床边指闹钟/拉被角，闹钟7:00。
- 妹妹：“二哥，七点啦！说好今天陪我逛街的。”
- 哥哥：“……起，给我两分钟。”

### 第2页｜收拾出门
- 画面：玄关，妹妹外出服已就绪回头催促，哥哥外出服提袋跟上。
- 妹妹：“收拾好了，出发！”
- 哥哥：“嗯，走吧。”

### 第3页｜挑衣与“不许敷衍我”
- 画面：服装店，妹妹拿浅蓝开衫在身上比划（**尚未穿上**），哥哥认真看。
- 妹妹：“这件怎么样？”
- 哥哥：“你先试，我看看。”
- 妹妹：“那你不许敷衍我。”
- 禁止：本页不得出现夸奖句，夸奖必须等妹妹穿上之后。

### 第4页｜穿上之后才夸（新增）
- 画面：妹妹穿上同一件浅蓝灰开衫从试衣间出来，原米色马甲叠好搭在手臂上；哥哥正面看她，**右手轻拍妹妹头顶（摸头）**，眼神不闪躲。旧版张掌像发誓／叫停，已整页重绘。
- 妹妹：“换好了。”
- 哥哥：“没敷衍。很好看，这颜色很衬你。”
- 妹妹：“……那我要这件。”
- 说明：“没敷衍”跨页回答第3页的“不许敷衍我”。试穿后换回外出服，后续服装连续。

### 第5页｜买衣服试衣服：正装惊艳
- 画面：哥哥从试衣间出来，正装合身；妹妹短暂愣住、眼睛亮起来；哥哥耳根泛红、带汗珠、视线转向镜子避开她，镜中反射同步泛红；左下角米色纸购物袋内露出刚买的浅蓝灰开衫。
- 妹妹：“哇……二哥，你穿正装这么帅的吗？”
- 哥哥：“……嗯。别看了。”（用户裁定，替掉与第2页重复的“嗯，走吧。”；害羞避视线，与画面表演一致）

### 第6页｜一起吃美食
- 画面：小吃街/餐桌，妹妹递一口食物给哥哥，哥哥尝。
- 妹妹：“这个好吃，你尝一口。”
- 哥哥：“嗯，不错。”
- 妹妹：“那再给我留一点。”

### 第7页｜双人共食活动前置（新增）
- 画面：咖啡馆门口立式看板（只画图不写字）：巨型巴菲＋杯中两根斜插的简笔长柄餐具（看板图标化画法，顶端圆润、不画勺碗） → 两个手拉手小人 → 箭头 → 限定挂件与小手办。妹妹眼睛发亮指着看板，**另一只手真实捏住哥哥袖口**；哥哥面无表情＋汗珠、**右手提着米色纸购物袋**（v7.1 由落地改为提在手上，已重新生图，地面无重复袋）。
- 妹妹：“两个人一起吃完，就送这个挂件！”
- 哥哥：“……所以你才拉我来。”
- 作用：为第8页“两人共食一份”提供动机，同时给妹妹的害羞强撑一个具体对象。

### 第8页｜一份巨型巴菲，两人各吃一半
- 画面（**v7.1 实图，v7.2 复核**）：单个高脚杯巨型巴菲置于两人之间，**全画面恰好两把长勺**——哥哥手中一把（带勺碗）、杯中斜插一把（只露长柄、勺碗没入奶油）。**四只手全部在桌面以上，桌下完全不画手／拳头／袖口／袖管**：妹妹左肩→胸前一干净张开手贴在衣领、右肩→桌面平放手；哥哥两肩→一握勺手＋桌面平放手。每人恰好 **2 条袖管 2 只手**（按肩线数袖管验收，不再只数手指）。两人脸红到耳根、紧张眉、视线躲闪、汗珠、紧抿嘴。v6 三手三勺、v7.0 三条袖管两次错误，最终整张弃用重新生成；桌下留白同时构成情绪特写的呼吸感，画风与 `shot-01.png` 锚点一致（详见 `docs/第三话_v7.2_全项复核与封面标题候选.md`）。
- 妹妹：“一人一半……你不许笑我。”
- 哥哥：“……嗯，不笑。”
- 禁止：不得画成闭眼恬静微笑（那是享受不是害羞）；不得出现吸管；台词不得只描述道具；**不得出现第三只手、第三把勺或任何多余肢体**。

### 第9页｜拍大头照
- 画面：大头照机前，妹妹拉哥哥靠近，屏幕/取景框可见两人。
- 妹妹：“靠近一点，看镜头！”（左上）
- 哥哥：“这样？”（右上）
- 妹妹：“对，笑一下嘛。”（左下）
- **阅读顺序必须是 妹→哥→妹**。上一轮曾把妹的第二句排在哥提问之前造成答在问前，已修正；几何审计查不出这类错误，必须逐句读。

### 第10页｜女同学疑问与指定回答
- 画面：妹妹抱着哥哥手臂；妹妹女同学在场并先疑问。哥哥不吐槽、不解释。
- 女同学：“小希，这位是？”（v7.3 用户裁定：原句缺称呼显唐突；“小希”＝江辰希，同班同学昵称）
- 妹妹：“这个是我男朋友。”
- 禁止：任何“这是我哥”、误会澄清、哥哥吐槽、同学继续追问。

### 第11页｜回家同睡与姐姐带侄女上床
- 画面：哥哥床上妹妹与哥哥已躺下/盖被；姐姐回家看到吃醋，带小满也爬上床。哥哥不接话，以动作容纳。
