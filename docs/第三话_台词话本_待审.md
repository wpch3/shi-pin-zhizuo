# 《二弟的休息日被全家预约了》
## 第三话｜台词话本 · 10页制作版

**结构：封面＋9页正片，共10页。** 本话以妹妹江辰希与二哥江星野的一天为主线，按已确认的八个事件推进，不增加其他活动或分别支线。用户已确认“可以10页，先做出来”，本版已用于实际生图与排版。

第8页的问答按你的指定原句锁定；其余对白为制作版台词。以下附简短画面提示，方便对着成品看节奏。

---

### 封面｜妹妹主场
独立街景，妹妹穿外出服，在前景明亮地笑着，轻拉哥哥的袖口；哥哥在后景提袋陪伴。突出妹妹的魅力与活力。

封面只放系列名和“第三话”，不增加事件标题或台词。

### 第1页｜七点叫起床
清晨卧室，妹妹穿家居服在床边叫哥哥，闹钟显示7:00；哥哥还困着。

- 妹妹：“二哥，七点啦！说好今天陪我逛街的。”
- 哥哥：“……起，给我两分钟。”

### 第2页｜收拾出门
玄关，妹妹已经换好外出服，回头催促；哥哥穿外出服、提袋跟上。

- 妹妹：“收拾好了，出发！”
- 哥哥：“嗯，走吧。”

### 第3页｜买衣服、试衣服：哥哥真心夸妹妹
服装店，妹妹拿着浅蓝开衫在身上比划，认真征求哥哥意见；哥哥在旁看着，不敷衍。

- 妹妹：“这件怎么样？”
- 哥哥：“你先试，我看看。”
- 妹妹：“那你不许敷衍我。”
- 哥哥：“没敷衍。很好看，这颜色很衬你。”

### 第4页｜买衣服、试衣服：妹妹被哥哥正装惊艳
哥哥从试衣间出来，正装合身；妹妹短暂愣住、眼睛亮起来。正装只是试穿，后续外出段仍穿原外出服。

- 妹妹：“哇……二哥，你穿正装这么帅的吗？”
- 哥哥：“嗯，走吧。”

### 第5页｜一起吃美食
小吃街餐桌，妹妹把好吃的递到哥哥面前，让他尝一口。

- 妹妹：“这个好吃，你尝一口。”
- 哥哥：“嗯，不错。”
- 妹妹：“那再给我留一点。”

### 第6页｜一起喝一杯饮料
两人各含一个吸管头。**道具是一杯饮料＋一根Y形双头吸管：一个杯身、一个液面，上端分成两个入口。**

- 妹妹：“两头吸管，正好一起喝。”
- 哥哥：“嗯，一起。”

### 第7页｜拍大头照
大头照机前，妹妹拉哥哥靠近，两人的脸进入取景框。

- 妹妹：“靠近一点，看镜头！”
- 哥哥：“这样？”
- 妹妹：“对，笑一下嘛。”

### 第8页｜女同学问起
妹妹抱着哥哥手臂，女同学在场，先问妹妹。**本页只有以下两句，不加哥哥吐槽、身份澄清或同学追问。**

- 女同学：“这位是……？”
- 妹妹：“这个是我男朋友。”

### 第9页｜回家睡觉，姐姐吃醋
回家后换家居服。哥哥和妹妹已在床上躺下；姐姐回来看到，吃醋，带着小满也爬上床。哥哥不接话，以动作容纳她们。

- 姐姐：“我才回来，位置就被你们占完了？”
- 小满：“小叔，我也要！”
- 姐姐：“走，小满，我们一起。”

**本话结束。**
