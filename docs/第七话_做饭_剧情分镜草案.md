# 第七话｜做饭的家庭时光（工作代称，标题待用户决定）

## 已确认方向与执行
妈妈有事没空做饭；厨艺极好的超级天才二弟掌勺，姐姐作为帮厨，两姐妹都能做饭，但这次妹妹先玩手机，不把她写成不会做饭。小满可以参与安全的摆餐具。大家吃饭后替妈妈留晚餐，妈妈回来看到纸条以及微波炉内的晚餐。第六话是水族馆，本话不再把水族馆当成“明天才去”。妈妈作背景点缀，不抢四位主角的主线。以下具体菜式、镜头和台词是制作细化，可由用户调整。

## 封面＋6页分镜
- 封面：厨房中二弟掌勺、姐姐在一旁帮厨；妹妹和小满从安全距离看向他们，暖色家庭气氛。只画画面，不提前决定标题或生成文字。
- 01 前提：家中客厅，姐姐拿着手机告知妈妈今晚有事；二弟主动承担。姐姐「妈妈今晚有事，来不及做饭。」二弟「那今晚交给我吧。」手机屏幕不画可辨文字。
- 02 合作：厨房里二弟料理热锅，姐姐在一旁洗菜或备菜，体现熟练配合。二弟「姐姐，菜洗好给我就行。」姐姐「好，主厨请吩咐。」厨具动作和炉火的安全距离清楚。
- 03 各司其职：妹妹在餐桌边看手机，小满认真摆不易碎的餐具；妹妹留意小满，不使用刀火，不以此否定她会做饭。小满「我来摆餐具！」妹妹「好，我帮你看着。」
- 04 出锅：二弟完成一盘色香俱佳的家常菜，姐姐协助端盘；小满和妹妹在餐桌旁等候，四人距离和手脚清楚。姐姐「香味都飘过来了。」二弟「最后一道，也好了。」
- 05 团聚：四人坐在餐桌旁吃家常晚餐，小满尝后开心；二弟手艺通过饭菜和家人的反应体现，而不是口头吹嘘。小满「小叔做的饭真好吃！」二弟「喜欢就多吃点。」
- 06 留饭：妈妈晚些回家，发现纸条和微波炉内留好的晚餐；她自然微笑，画面以微波炉及留饭为叙事焦点。纸条画空白，后期精确排入候选文字「妈妈，晚饭给您留在微波炉里了。记得吃哦。」妈妈「真贴心。」纸条实际措辞是提案；不能由模型生成假字，微波炉内餐盘可见但不画加热操作。

## 连贯性与自查
菜式限定为简单家常饭菜，盘碗造型在相邻页尽量一致；手机只在01/03使用，03后可收起；热锅只在02/04出现，餐具只在03以后出现。四位家中服装参考第五话已认可的家居段：二弟深蓝卫衣灰裤、姐姐米色毛衣深色裤和眼镜、妹妹米白上衣深蓝裙双辫、小满格纹裙芽芽发饰。妈妈只在末页露面；任何人物道具从袖管追到手，遮挡不强判，明显多肢体不可辩解。排字后检查阅读次序及气泡归属。无用户裁定的正式封面标题，暂不上字。

分镜逻辑核对：妈妈不做饭→二弟接手、姐姐帮忙→妹妹和小满在旁→出菜→同桌用餐→妈妈回家收到留饭，原因、人物任务和时间顺序均已交代；可开始制作。所有正文对白和纸条措辞为候选，不代表用户已审定。

## 用户新要求：中餐丰盛＋炊具合理＋补留饭过程
用户指出原首轮02页液体食材配平铲让人以为用铲子煮汤，希望饭菜更多、更丰盛，以中国家常菜或能体现厨艺的菜系为主，桌子要大。调整为：清蒸鱼、番茄炒蛋、清炒青菜、家常汤及米饭；炒菜用锅铲且锅内为炒菜，汤单独在汤锅用汤勺，不再把平铲伸进汤。桌子为足够容纳四人和多道菜的大餐桌，四人餐具与公共餐具分清。菜式是本次具体候选，后续可按用户口味改。

补一页承上启下：吃完饭，二弟和姐姐将给妈妈的饭装入可微波容器放进微波炉，留下字条；再画妈妈回家看到留饭与纸条。顺序为：封面＋01消息→02炒菜与备菜→03妹妹玩手机、小满摆餐具→04四菜上桌前完成→05四人共餐→06单独留饭与纸条→07妈妈回家。这样不用靠读者猜谁留的饭。具体对白参考：02姐姐「青菜洗好了，鱼也快蒸好了。」二弟「我再炒一道，汤马上好。」03小满「我来摆餐具！」妹妹「好，我帮你数一数。」05小满「小叔，今天的菜好丰盛！」二弟「喜欢就多吃点，也给妈妈留一份。」06姐姐「妈妈回来就能看见了。」纸条候选「妈妈，晚饭给您留在微波炉里了。记得吃哦。」07妈妈「你们真贴心。」只作为初步对白，不把纸条内容当用户指定原句。
