# 02 · 命名提案：见秋 / 知冬 / 逢春 / 听夏 / 小满

姓氏取 **林**。

| 名字 | 身份 | 年龄 | 名字里的意思 |
|---|---|---|---|
| **林见秋** | 大哥 | 29 | 一叶知秋。他是家里最先"看见季节变化"的人，也最先离开家 |
| **林知冬** | 姐姐 | 27 | 知冬。冷，克制，是她在外面的样子 |
| **林逢春** | 二哥 | 25 | 逢春。枯木逢春，全家最暖的那个人 |
| **林听夏** | 妹妹 | 18 | 听夏。她只负责"听"和"黏"，不负责说 |
| **林小满** | 侄女 | 5 | 小满。二十四节气之一，"小得盈满" |

## 为什么是这一套

**1. 四个动词，一家人从不直说。**
见、知、逢、听——全是"感知"，没有一个"说"。这正好是《全家都在藏私》的语法：这一家人不解释自己，只互相看着、猜着、接着。名字本身就是主题。

**2. 长幼顺序刚好是一个完整的四季回环。**
见秋 → 知冬 → 逢春 → 听夏。秋尽而冬，冬尽而春，春尽而夏。念一遍就能感觉到"这一家人自己就是一个世界"。

**3. 小满是唯一的"节气"，不是四季。**
她是下一代，用另一套命名规则在逻辑上才对；叙事上，她是全家唯一不设防、什么都不藏的人——**所有人都在藏，只有小满是真的"满"的。**

**4. 名字和人设咬合。**
- 知冬最冷，人也最冷（在外面）；
- 逢春最暖，人也最暖（全家的插座）；
- 见秋是"看见秋天的人"，所以他一年才回一次家，看见的都是别人的季节。

## 备选方案（如果嫌"季节"太常见）

| 方案 | 名字 | 优点 | 缺点 |
|---|---|---|---|
| A. 风花雪月 | 林风 / 林花 / 林雪 / 林月 | 直白好记 | "风花雪月"自带旖旎歧义，且"花"做男孩名尴尬 |
| B. 笔墨纸砚 | 林砚 / 林墨 / 林笺 / 林纸 | 文房意象很雅 | "纸"做名字太硬 |
| C. 江河湖海 | 林江 / 林川 / 林汐 / 林海 | 三点水，温柔 | 缺"关系感"，四个人像没关系 |
| D. 节气全家桶 | 惊蛰 / 白露 / 芒种 / 小满 | 有个性 | "芒种"不好念，也不像人名 |

**推荐 A 案（见秋 / 知冬 / 逢春 / 听夏 / 小满）**，已在人物设定卡与页脚人物条落地。

## 改名怎么改

只动两个文件：

- `tools/build_cast.py` → `HEADS`（页脚人物条）
- `tools/build_cards.py` → `CARDS`（人物设定卡）

改完依次跑：

```bash
python3 tools/build_cast.py
python3 tools/build_cards.py
python3 tools/build_pages.py
python3 tools/make_pdf.py
```
