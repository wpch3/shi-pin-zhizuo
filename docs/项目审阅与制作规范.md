# 《回家以后》项目审阅与制作规范

## 一、已完整读取的材料

- 原文件：`4d1909a5-266e-4407-8566-7ce0b879cf9e.pdf`
- 共 9 页。PDF 页面为聊天截图图片，无可直接提取的文字层；已逐页渲染阅读，并提取原始截图核对关键人设卡。
- PDF 主要包含：初始家庭人设、既有立绘、画风讨论、七位成员的人设卡、第一话五张横图方案，以及后续故事方向。
- 仓库除 PDF 与 README 外没有上个 AI 的可编辑工程、原始分层图或脚本，因此本次重新建立可持续修改的制作结构。

## 二、不可变更项

1. 以 PDF 中用户原始要求和可见人设卡文字为准，锁定父亲、母亲、大哥、姐姐、二哥、妹妹、小侄女七人。
2. 不新增官方姓名、具体年龄、额外亲属关系，不把亲情擅改成恋爱关系。
3. 保留既有视觉识别：父亲西装公文包；母亲低盘发与围裙；大哥深蓝西装；姐姐长卷发、眼镜与职业装；二哥自然黑发、米色开衫与笔记本电脑；妹妹长直发与深蓝校服；小侄女短发与彩虹裙。
4. 完整设定原文见 `data/characters.json`，人设卡中的“设定原文”均从该文件直接排版。
5. 用户要求的最终形式不是配音视频：**纯漫画，无语音；每页四格；每话四至六页。**

## 三、上个 AI 方案是否可行

### 可保留的核心

- “外人在场时优秀可靠，回到家人面前展现松弛与依赖”的反差清楚，适合日常短篇。
- 二哥看似在家、实则能处理父亲交办的大项目，是能够支撑连续故事的有效矛盾。
- 大哥常年在外地，以视频通话进入家庭场景，符合人设且制作稳定。

### 必须修正的部分

| 问题 | 审阅结论 | 本次处理 |
|---|---|---|
| 形式仍是横图加配乐剪辑 | 不符合现在明确的纯四格漫画要求 | 改为五页、二十格，文字直接排入页面 |
| 人设说明集中 | 前几格像角色介绍，缺少事件牵引 | 用“完成父亲交办的项目”贯穿全话 |
| 反差重复 | 姐姐、妹妹都只在门口喊二哥，动作雷同 | 分别安排回家、卸下职业状态、依赖二哥的不同节拍 |
| 大哥只负责暴怒吐槽 | 功能单一，也削弱其优秀可靠的形象 | 同时确认二哥的工作成果并参与家庭晚饭 |
| 画面文字由生成模型直接书写 | 容易错字、乱码、字距混乱 | 所有中文在排版阶段用字体统一绘制 |
| 正比与 Q 版频繁切换 | 容易削弱角色一致性 | 本话统一清淡正比，表情符号只作少量辅助 |
| 画面曾出现多余手臂、发色偏差 | 属于明显制作事故 | 新立绘逐张检查，固定二哥自然黑发 |

## 四、光影是否太浓

**是，既有室内图的光影与氛围效果偏浓。** 大面积金色逆光、粉色光斑、强轮廓光和过高暖色饱和度，会让人物与对白退居其次，也使不同场景看起来相似。

本话统一采用：

- 清淡日系线稿与平涂赛璐璐；
- 中性柔和室内光，降低明暗反差；
- 不使用大面积金色夕阳、粉色滤镜、泛光和密集爱心；
- 阴影只用于交代体积，不用厚重渐变遮住线稿；
- 页面留白和对白框优先保证手机端阅读。

## 五、第一话故事优化

- **话名：**《回家以后》第一话「外人眼里的他们」
- **规格：**5 页 × 4 格，共 20 格。
- **主线：**姐姐、妹妹、大哥在外各自可靠；二哥在家认真完成父亲交办的项目。姐姐与妹妹回家后对他展现依赖，小侄女也黏上来。大哥视频时没有只负责生气，而是带回父亲对项目的肯定。母亲叫全家吃饭，父亲因工作仍不在家，大哥也仍在异地。
- **收束：**“在外面，他们各自发光。回到家，只是彼此最亲的人。”
- **边界：**人设卡原文完整保留；第一话不反复使用洗澡梗，不额外解释“小侄女的父母是谁”等 PDF 未确定信息。
