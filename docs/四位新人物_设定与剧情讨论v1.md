# 四位新人物｜设定与后续剧情讨论 v1

> 本文与人设图均为供审阅的试案，不代表姓名、背景、关系进程或剧情已经发生，也不自动修改已确认章节。妹妹好友的现有体型优化图已获用户认可；邻居姐妹和小姨的本次图像仍待确认。下文的性格细节和故事均是助手建议，用户设定优先。

## 1｜妹妹的好友：安静、慢热的“猫系”同学

**用户确定方向**：江辰希的好朋友；身材娇小、体型丰满，蓝黑发，妹妹同款校服；人类而非猫娘；病弱感、猫系气质，脸和性格参考陆奥驹絽；以后会见到哥哥并迷上他。名字暂不指定，也不默认她是第三话同学或旧预案人物。

**性格优化提案**：平时安静省力、在人多的场合容易紧张；熟悉之后话不多但观察细致，偶尔以一本正经的语气说出意外好笑的话。她对好友的情绪很敏锐，能听见辰希不经意提起哥哥时语气的变化，也会在辰希讲题太快时坦率地说“这里我没跟上”。她会主动表达自己的意愿，不是只等人照顾；累的时候学着及时休息和求助，也会在自己擅长的地方帮朋友。

**背景建议**：体力不太稳定，需要合理安排作息，因此习惯把事情提前记在小本子上；没有指定疾病、病因或严重程度。她喜欢画小小的手账插图，尤其擅长把复杂步骤画成清晰的小图解。和辰希因一次整理笔记熟悉：辰希看懂题目，她把解题过程画得一目了然，两人互相欣赏。她可以有自己的学习目标和朋友关系，不把全部生活写成生病或喜欢哥哥。

**与哥哥相识及好感的渐进提案**：
1. **先建立好友关系**：第八话仍以辰希的课堂表现、友情和想念哥哥为主；好友一起学习、发现她总惦记哥哥。暂不强行安排两人首次见面。
2. **自然见面**：后续一个放学日，辰希和好友在校门口等家人。星野来接妹妹时，辰希主动介绍好友；他注意到好友累了，先询问她需不需要在附近坐一会儿，也尊重她的回答，不替她做主。
3. **好感有具体原因**：下一次大家一起整理校园活动材料，星野认真听她解释自己的图解，夸的是她的思路，而不是只把她当成需要照顾的人。她记住这份被平等对待的温柔，也愿意主动把自己的小插图送给大家。
4. **性格化的喜欢**：她开始期待在辰希身边遇见这位可靠的哥哥，悄悄记住他的喜好，却也会认真关心好友，不与辰希的友情互相取代。现阶段可写成少女单方面的欣赏与憧憬；星野保持可靠哥哥式的关心和合适边界，不写成人与未成年人的恋爱关系。具体强度和对白由用户决定。

可选对白示例（非定稿）：好友看着自己画的解题图，小声说：“原来你哥哥真的会认真听我讲完。”辰希笑着回答：“当然啦，他就是这样的人。”

## 2｜隔壁姐姐：安静外表下的创作者

**用户确定方向**：隔壁姐妹中的姐姐，刚上初中；姐妹统一沿用妹妹原图的暖橙棕发。原预案为表面冷淡、内心脑补丰富、隐藏人气VTuber。原图另有为妹妹制作Cos服的内容，可作为参考。

**优化提案**：安静不是不关心人，她习惯先观察、想清楚再表达；喜欢设计虚拟形象和服装，也愿意给妹妹的演出或Cos服出主意。面对新环境不擅长主动交友，但做熟悉的事时会十分专注；偶尔脑补过头，回过神再自己纠正。她有独立的创作目标与同龄人关系，不把秘密身份当成唯一笑点。

**对星野的好感与戏份建议**：把他视作让人安心、尊重别人秘密的邻家哥哥。一次他在姐妹二人忙着准备活动时帮忙搬材料，却没有追问图纸，她因此更加信赖他；她用亲手做的小物件表达感谢。直播身份是否揭晓、何时揭晓均待用户决定；不把这段好感写成成人与初中生的恋爱。

## 3｜隔壁妹妹：爱挑战的四年级小选手

**用户确定方向**：小学四年级，原预案的日常、Cos与花滑两张图为同一人；与姐姐发色一致，沿用暖橙棕发。原图包含花滑、Cos及有点傲娇的活泼表现。

**优化提案**：喜欢挑战、嘴上不服输，练花滑时却愿意反复练习基本功；她会小小恶作剧，但知道让朋友不舒服时应该停下并道歉。姐姐为她做服装，她也会主动帮姐姐挑配色或收拾材料。喜怒和失误都符合小学生年龄，不写成小大人。

**对星野的好感与戏份建议**：把他当成喜欢一起玩、愿意为她加油的邻家大哥哥。她表面说“这次我一定能做好，不用担心”，比赛结束后又开心地跑来分享练习成果；也可以和小满一起玩，在相处中学习照顾更小的孩子。以孩子式亲近和崇拜呈现。

## 4｜小姨：直率又有分寸的行动派

**用户确认关系**：她是大哥妻子的妹妹，即小满的小姨；不是江家妈妈的妹妹，不沿用旧预案人物的姓名、职业和经历。原图的时髦、直球、偶尔迷路或家务出糗可作为性格方向参考。是否成年、具体年龄及职业由用户确认；本次立绘暂按成年形象试画。

**优化提案**：表面外向健谈、喜欢轻松开玩笑，实际上很会观察气氛，别人不愿意聊的话题她会收住；在自己擅长的事情上可靠，面对陌生路线则会提前做路线卡，偶尔还是走错。她与姐姐和小满有自己的亲情故事，不只是为了制造“求救”而登场。

**对星野的好感与戏份建议**：因为小满与家人活动逐渐熟悉，欣赏他对家人的耐心和实际行动；她也能主动帮他解决自己擅长的问题，两人互相帮助，而非她次次出糗等他救场。若用户确定她与星野均为成年人且希望发展恋爱，可再讨论以平等、自然的相处逐渐加深好感；具体关系尚未定稿。
