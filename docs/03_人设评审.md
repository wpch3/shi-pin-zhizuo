# 03 · 人设评审：这套人设能用，但有三处必须动

先说结论：**记忆点很足，是一套能出梗的人设。**"姐姐断电 / 妹妹装 / 二哥扮猪吃虎 / 侄女挂件"这四个点，每一个都能单独剪一条短视频。

但有三处必须改，否则会影响发布。

---

## 一、必须改：「弟弟的梦想是跟三个女人结婚」

**问题：** 这句字面就是多妻 + 骨科暗示。B 站 / 抖音的审核对这类表述很敏感，而且它会把整部作品的调性，从"温馨家庭喜剧"一秒钟拽到"擦边"。

观众看到这句的第一反应不是笑，是"这什么设定"，**梗没有落地，反而劝退**。

**改法（保留笑点，换落点）：**

> 梦想是跟家里三个女人住一辈子，谁都不许嫁出去。

同一个"想要三个女人"的梗，落点从"结婚"变成"舍不得分开"，顺便把"姐控 + 妹控"立住了，也不违规。

---

## 二、建议改：三处「一起洗澡」

原设定里，"洗澡"出现了三次：姐姐跟二弟一起洗、妹妹跟二哥一起洗、侄女的"跟小叔一起睡"也挨着。

**问题：** 未成年妹妹 + 成年哥哥"一起洗澡"，加上侄女"跟小叔一起睡"，这些叠加在一起，舆论风险很高——哪怕本意是"兄妹感情好"，评论区也一定会歪。

**改法：保留"习惯传承"的趣味，换掉场景。**

你原设定里真正好笑的其实不是"一起洗"，而是**"这个家的生活习惯都是二哥带出来的"**：

| 保留 | 改掉 |
|---|---|
| 妹妹"先泡澡后冲洗"是跟二哥学的 | ✂ "一起洗澡" |
| 二哥挤牙膏从中间挤、拖鞋永远摆不正 | ✂ "教了很多坏习惯"里的身体相关部分 |
| 侄女睡前必须小叔讲故事，一讲就是三遍 | ✂ "经常跟小叔一起睡觉" |

"先泡后冲"这个细节**非常好**——它是一个人能被另一个人影响多深的证据，而且完全安全。建议把它留作兄妹关系的"物证"。

---

## 三、需要补：大哥没有"对内"的人设

原设定里大哥是：常年在外地 / 距离老家远 / 四兄妹里唯一只有本科学历 / 自身很优秀 / G 企项目总经理。

这是**背景**，不是**人设**。观众对他没有情绪，因为他在故事里只承担"对比"功能。

**补法（本次已用）：**

> 手机相册里 482 张家里的照片。一张都没发过。也一年没回过家。

冷面经理的"私"，是"想家"。这一格是全片的情绪落点，也让"藏私"这个题眼真正收口——**全家人藏的是懒、是装、是啃老；他藏的是想念。**

---

## 四、四个逻辑补丁

**1. 学历 vs 职位**
"全家唯一只有本科学历" vs "G 企项目总经理"——不矛盾，但要一句话点破：

> 全家学历最低的人，是唯一养得起全家的人。

这既是笑点，也是他的痛点，第 2 话可以拿来用。

**2. 缩写观众看不懂**
"SHJD 博士""SUD 博士"原稿两种写法都有，观众不知道是什么。统一写成 **"交大博士"**。

**3. 城市混乱**
CQ 一中 / 上海 / 南方工地，三个地点没有交代关系。建议：老家设为虚构城市 **"江城"**，姐姐在上海，大哥在南方项目。三地关系一句话能讲清。

**4. 母亲是全片藏得最深的人**
"全职主妇" + "每天去自家超市收租兼收银"——这是极好的人设反差，但原稿只当背景写了。

建议坐实：**外人以为她是养尊处优的阔太，其实全家的账、超市流水、四个孩子的开销都在她手里。** 她是家里真正的"财阀"，可以作为第 2 话的爆点（已写进连载规划）。

---

## 五、一句话总评

| 角色 | 他的"私"是什么 |
|---|---|
| 姐姐 | 高冷是省电模式 |
| 妹妹 | 完美是外壳 |
| 二哥 | 啃老是伪装 |
| 大哥 | 冷面是想家 |
| 小侄女 | 唯一不设防的人 |

五个人刚好构成一条完整的"藏私"光谱——**这套人设可以支撑一整季，不需要再改结构。**
