# 全家都在藏私 · 竖屏短篇漫画

一个 B 站竖屏短漫 / 漫剪项目：**外人眼里的神仙家庭，其实全家都在藏私。**

- 规格：1080 × 1920，第一话 6 页，约 36 秒
- 全部中文由代码排版（不靠 AI 生成文字），画面统一平涂赛璐璐光照
- 从人物设定图到成片，一条命令可完整重建

## 重建

依赖：Python 3.9+、Pillow、fontTools、pymupdf（导出旧版对照图）、imageio-ffmpeg（合成视频）。

```bash
pip install pillow fonttools imageio-ffmpeg pymupdf

# 首次需要完整字体（约 90MB 源码包，仅取 Regular / Medium）
bash tools/get_fonts.sh

# 如果改了文案，重新子集化字体（缺字会显示成方框）
python3 tools/subset_font.py

# 依次出图
python3 tools/build_cast.py     # 页脚人物条
python3 tools/build_cards.py    # 人物设定卡
python3 tools/build_pages.py    # 6 页漫画
python3 tools/make_pdf.py       # PDF + 连览图
python3 tools/make_compare.py   # 光影对照图
python3 tools/make_video.py     # 36s 竖屏漫剪
```

改台词只需要改 `tools/build_pages.py`，其余全部重算。

## 美术规范（改画时请遵守）

**光**
- 单一柔和主光，从正面/侧前 30° 打；阴影只分两层（本色 + 一层浅影）
- 禁止：强逆光、边缘发光、泛光/丁达尔、镜头光斑、暗角
- 例外：情绪格（如深夜办公室）允许一点侧逆光，作为节奏对比

**色**
- 中低饱和、高调、纸感底色（#FBF7F1）；提亮中间调，暗部不压死

**线**
- 细而干净的赛璐璐线稿，平涂 + 两层阴影，不用厚涂光泽

**字**
- 全部由 `tools/build_pages.py` 排版，禁止把中文交给图像模型生成

**Q 版**
- 只在「反差瞬间」使用；2.5 头身、粗描边，但**配色与线宽必须和正比一致**

**一致性**
- 每张分镜生成时都必须以 `assets/art/00_character_sheet.png` 作参考图

## 与上一版的主要差异

1. **光影压平**：去掉强逆光与泛光，阴影 3–4 层降到 2 层，中间调提亮 → 竖屏连读不疲劳。
2. **锁定人物**：先出设定图，再逐格生成，解决姐姐「忽有忽无的眼镜」、二哥发色漂移等问题。
3. **中文代码排版**：图像不再承担文字，杜绝错字，改词不用重画。
4. **补上情感落点**：小侄女明确为大哥的女儿 → 二哥的「啃老」变成替哥哥带孩子 → 大哥的吃醋变成想家（结尾 482 张照片）。
5. **结尾重写**：从「我不是不让你们黏二弟」这种没打中的抱怨，换成一句能让人记住的「一张都没发过」。
