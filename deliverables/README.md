## 整理原则

1. **入口分层**：日常阅读进“分格式阅读区”，制作中的内容看对应进度，旧版仅作追溯。
2. **版本标清状态**：已确认、局部确认、制作中、历史候选分开说明；每话只把当前版本放在阅读入口主表。
3. **物理归档**：交付区根目录散装文件与章节工作版本已按[话数](章节/README.md)或[人物](人物资料/README.md)、[短篇](短篇与个人回/README.md)、[历史资料](历史资料/)分类；原第一二话跨话[逐页索引](历史资料/跨话索引/第一二话_逐页看图.md)保留，原画 `art/` 和其他用户源文件未迁动。迁移与验证见[整理台账](../docs/交付区整理_分批迁移台账.md)。
4. **保护原文件**：移动时更新仓库内链接、脚本及符号链接并检查，未覆盖母版；由于路径改变，外部保存的旧直链可能失效，应该使用本页新入口。未确认用途和依赖的旧文件先保留，不批量删除。每话整理完成后仍以阅读区里的版本状态为准。

本索引是导航，不代表所有章节或角色都已通过验收。
