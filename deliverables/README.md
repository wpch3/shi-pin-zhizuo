## 整理原则

1. **入口分层**：日常阅读进“分格式阅读区”，制作中的内容看对应进度，旧版仅作追溯。
2. **版本标清状态**：已确认、局部确认、制作中、历史候选分开说明；每话只把当前版本放在阅读入口主表。
3. **保护原文件**：本轮仅新增入口和第七、八话阅读文件；历史目录暂时仍在根目录，没有搬移或删除，旧链接、制作脚本和用户确认原图不因此失效。目录列表本身仍会显得拥挤。
4. **未来如需物理归档**：先核查所有 Markdown 相对链接、脚本输入和用户确认状态，做可回滚映射，再统一迁移历史目录并验证；未核实前不批量移动或删除。新增内容优先进入明确的阅读入口或工作目录，避免在根目录继续散放。
