## 怎么选格式

- **逐页看图**：Markdown 内嵌原尺寸 PNG，适合在仓库中阅读；需要保留仓库相对路径。
- **完整版 PDF**：第1—6话为原尺寸 JPEG q96、4:4:4（有损）；第7—8话为 PNG/Flate 无损，和对应逐页 PNG 像素一致。大文件在部分网页中可能无法预览，请下载或改看 Markdown。
- **轻量 PDF**：用于快速预览；第1—6话为不超过720×960、JPEG q90；第7话沿用 v7 压缩预览（最长边不超过1050、JPEG q90）；第8话沿用已确认 v11 的压缩预览（源图 JPEG q85、PDF 页面最长边720点）。轻量版并非无损母版。
