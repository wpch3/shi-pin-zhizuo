# 短篇故事集

全部故事以PDF中的人设为唯一基准，不启用未经确认的新名字。漫画规格均为每页四格，每话四至六页。

## 独立单元剧

1. [《只耽误一分钟》](单元剧_只耽误一分钟.md)  
   4页16格。二哥赶父亲交办的项目，姐姐、妹妹、小侄女分别用“一分钟”围住了他。

2. [《姐姐今天不撒娇》](单元剧_姐姐今天不撒娇.md)  
   4页16格。姐姐宣布不再犯懒，妹妹和小侄女轮流验证，最终在工作通话结束后集体恢复原状。

3. [《装进行李箱的二哥》](单元剧_装进行李箱的二哥.md)  
   4页16格。妹妹准备英国留学行李，姐姐和小侄女加入讨论，最后发现真正装不进去的是对二哥的依赖。

## 连续短篇

[《三天以后，二哥归我们》](连续短篇_三天以后二哥归我们.md)

共3话，每话4页16格，总计12页48格。

- 第一话《大项目来了》：二哥接下三天后终审的大项目，姐姐、妹妹、小侄女与他约定补偿。
- 第二话《谁都不许叫醒他》：第三天清晨，三个人守着刚睡着的二哥；终审电话仍然让他立刻进入工作状态。
- 第三话《三天以后，二哥归我们》：终审通过，三个人拿出各自记录的补偿清单，连续约定在晚饭后收束。
